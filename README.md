#  ESP32 WiFi NTP Alarm Clock

Ένα έξυπνο ψηφιακό ρολόι-ξυπνητήρι βασισμένο σε **ESP32**, το οποίο συγχρονίζει αυτόματα την ώρα μέσω WiFi (NTP server), προβάλλει την ώρα και το ξυπνητήρι σε οθόνη **OLED (SSD1306)** και διαθέτει **buzzer** με κουμπί σίγασης.

##  Λειτουργίες

- **Αυτόματος Συγχρονισμός Ώρας (NTP):** Συνδέεται σε δίκτυο WiFi και λαμβάνει ακριβή ώρα από το `pool.ntp.org` (ρυθμισμένο για ώρα Ελλάδας: GMT+2 + θερινή ώρα).
- **Προβολή σε Οθόνη OLED (128x64):** Εμφανίζει ζωντανά την τρέχουσα ώρα (`ΩΩ:ΛΛ:ΔΔ`) και την ώρα του ξυπνητηριού (`Alarm: ΩΩ:ΛΛ`), με ανανέωση ανά δευτερόλεπτο χωρίς `delay()` (χρήση `millis()`).
- **Διακοπτόμενος Ήχος Ξυπνητηριού:** Όταν φτάσει η ρυθμισμένη ώρα, το buzzer παράγει διακοπτόμενο ήχο στα `1000Hz` (500ms ήχος / 500ms σιωπή) μέσω PWM (`ledcWriteTone`).
- **Κουμπί Σίγασης (Acknowledge):** Με το πάτημα του κουμπιού το ξυπνητήρι σταματά αμέσως και δεν ξαναχτυπά μέσα στο ίδιο λεπτό, ενώ επαναφέρεται αυτόματα για την επόμενη ημέρα.
- **Σταθερή Λειτουργία WiFi & I2C:** Απενεργοποίηση του WiFi sleep mode για σταθερή τροφοδοσία και ρύθμιση του I2C στα `100kHz` για αποφυγή παρεμβολών.

##  Υλικά & Συνδεσμολογία (Pinout)

### Απαιτούμενα Υλικά
- **ESP32** (DevKit)
- **Οθόνη OLED 0.96" SSD1306** (128x64, I2C, διεύθυνση `0x3C`)
- **Buzzer** (παθητικό ή ενεργό)
- **Κουμπί (Push Button)**
- Breadboard & καλώδια σύνδεσης

### Συνδέσεις με το ESP32

| Εξάρτημα | Pin Εξαρτήματος | ESP32 GPIO | Σημειώσεις |
| :--- | :--- | :--- | :--- |
| **OLED SSD1306** | SDA | `GPIO 21` | I2C Data |
| **OLED SSD1306** | SCK / SCL | `GPIO 22` | I2C Clock |
| **OLED SSD1306** | VCC / GND | `3.3V` / `GND` | Τροφοδοσία |
| **Buzzer** | `+` (Signal) | `GPIO 18` | PWM Channel 0 (`1000Hz`) |
| **Buzzer** | `-` | `GND` | Γείωση |
| **Push Button** | Πόδι 1 | `GPIO 19` | `INPUT_PULLUP` (Active LOW) |
| **Push Button** | Πόδι 2 | `GND` | Γείωση |
